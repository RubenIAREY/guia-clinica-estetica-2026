# Guía para planificar una clínica estética en España

Web interactiva y autocontenida para estructurar decisiones, autorizaciones, operaciones, privacidad, equipo y viabilidad económica de una clínica médico-estética o un centro estético no sanitario.

- Corte de fuentes: 18 de julio de 2026
- 45 fuentes públicas oficiales
- Funciona sin dependencias externas de ejecución
- Incluye checklist persistente y escenario financiero editable

## Aviso

Contenido informativo de planificación general. No constituye asesoramiento jurídico, sanitario, fiscal, técnico ni financiero, ni sustituye resoluciones o autorizaciones aplicables al caso concreto.
